# 贵州城市更新公示项目基础信息工作台

这是一个面向 Codex/前端开发继续扩展的可视化数据项目，用于把政府公示、公共资源交易公告和现场调研数据整理成项目基础信息面板。

当前版本使用模拟样本数据，重点验证三件事：

- 固定抓取公示页面，并为每个来源配置字段和解析器名称。
- 打开公示项目后，在面板中填充项目基础信息、来源、地址、责任单位和更新范围。
- 为项目补充周边数据接口，例如人流、空铺率、竞品数量、停车饱和度和夜间活跃度。

## 适用场景

- 城市更新项目线索归集
- 老旧小区、背街小巷、停车设施、文旅街区等公示项目整理
- 现场走访前后的项目基础档案管理
- 后续接入爬虫、地图、照片证据、访谈记录和数据复核流程

## 核心模块

1. **固定抓取源**
   - 配置公示页面、抓取频率、字段清单和解析器名称。

2. **公示项目池**
   - 按城市、项目类型、来源筛选项目。
   - 点击项目后联动基础信息面板和周边数据面板。

3. **项目基础信息面板**
   - 展示项目名称、主管单位、地址、土地用途、更新范围、资料完整度和原文链接。

4. **周边数据接口**
   - 预留人流、空铺率、竞品、停车、夜间活跃度等字段。
   - 每个指标保留状态和来源，方便后续现场补数或接口接入。

5. **7天数据行动表**
   - 从固定来源、抓取列表、解析原文，到现场补数、证据库和项目档案输出。
